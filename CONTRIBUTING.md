# 🤝 Contributing to BuildFlow

Loyihani rivojlantirishga qiziqish bildirganingiz uchun tashakkur!

## 🛠️ Qoidalar va Ko‘rsatmalar

1. **Fork qiling va yangi branch oching**:
   ```bash
   git checkout -b feature/yangi-imkoniyat
   ```
2. **Kodni tekshiring**:
   Kodingiz Clean Architecture tamoyillariga va mavjud Jetpack Compose dizayniga mos kelishini ta'minlang.
3. **Testlarni ishga tushiring**:
   ```bash
   ./gradlew testDebugUnitTest
   ```
4. **Commit xabarlari**:
   [Conventional Commits](https://www.conventionalcommits.org/) formatiga amal qiling (`feat:`, `fix:`, `refactor:`, `docs:`).
5. **Pull Request (PR) yuboring**.
